九州大学から見る未来社会｜第6版 GitHub Pages 網頁版

1. 解壓縮本 ZIP。
2. 將 index.html、slides 資料夾、thumbs 資料夾一起上傳至 GitHub Repository「AlexLIN0927/kyushu-future-lecture」根目錄，覆蓋舊檔。
3. GitHub → Settings → Pages → Deploy from a branch → main / (root)。
4. 開啟 https://alexlin0927.github.io/kyushu-future-lecture/
5. 若仍看到舊畫面，在 Mac Chrome 使用 Command + Shift + R。

操作：← → 換頁、N 講稿顯示切換、T 縮圖、F 全螢幕、手機左右滑動。
