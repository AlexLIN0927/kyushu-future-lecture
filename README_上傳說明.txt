九州大学から見る未来社会 第5版｜GitHub Pages 網頁版

這個版本包含26頁投影片，以及25頁 PowerPoint 中的日文講稿備註。
第26頁沒有講稿，因此會顯示說明。

【更新現有網站】
1. 登入 github.com/AlexLIN0927/kyushu-future-lecture
2. 在 Code 頁面上傳本資料夾內的 index.html、slides/、thumbs/、README_上傳說明.txt
3. 請覆蓋舊版檔案，務必維持 index.html 在儲存庫根目錄。
4. Commit changes 後，Pages 設定沿用 main / (root)，不必重新開啟。
5. 開啟 https://alexlin0927.github.io/kyushu-future-lecture/ ，必要時用 Command+Shift+R 強制重新整理。

【操作】
點擊前へ／次へ，或使用鍵盤 ← →；按 📖 顯示講稿或 N 鍵；T 開啟縮圖；F 全螢幕；手機左右滑動換頁。
網址可用 #slide-18 直接定位。

備註：投影片呈現以靜態圖片為主，不包含原 PowerPoint 動畫、影片播放功能。
